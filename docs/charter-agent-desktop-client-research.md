# charter-agent desktop client 研究筆記

## 一句話結論

`charter-agent` 的 desktop client 幾乎把「回合執行、串流、conversation chain、`agent_session_id` 對應 Hosted microVM、OAuth consent、M365 identity passthrough」交給 Foundry／Responses protocol；自己只做 Windows 登入、project preamble、每 project 保存 `session_id`／`previous_response_id`、UI busy lock、少數錯誤/consent/空回覆重試與本地快取。證據層級：**原始碼明寫**。

> 固定版本：`MSFT-Innovation-Hub-India/charter-agent@92a44cf3705a53620a9d38db54304396652b1857`。以下引用皆為 commit-pinned URL。使用者提到的 `desktop-client/charter_client/assets/app.js` 在此 commit 實際路徑是 `desktop-client/assets/app.js`。

| 使用者身分與 M365 | Foundry validate bearer；Toolbox Identity Passthrough 代換成使用者身份；OAuth consent event 由平台送出。 | desktop 取得 user token、附在 request、接 consent URL 開 browser 後重試。 |
| 工具執行 | MAF `Agent` + `MCPStreamableHTTPTool` + Foundry Toolbox。 | skill `allowed-tools` 解析、in-process state/domain tools、tool UI cards。 |
| 觀測 | 文件說 server-side spans/model/tool calls 由 Foundry/App Insights 自動輸出。 | `$HOME/activity.json` narrative audit；client log / UI toast。引用：[architecture_and_design.md#L415](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/architecture/architecture_and_design.md#L415)。 |
| Background | 沒有 server-side autonomous worker。 | desktop `AutoPoller` 用使用者 token 定時觸發 `/responses`。引用：[architecture_and_design.md#L20](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/architecture/architecture_and_design.md#L20)。 |

## 對 FA portal 的可借鏡處

以下只描述 `charter-agent` 做法本身與代價／風險，不評論 FA 目前程式。

1. **單一 protocol surface：只用 Responses，不做 invocations/自訂 action dispatcher。** 代價是 client 要理解 Responses 的 `previous_response_id`、SSE/tool-call/consent events。證據層級：**原始碼明寫 + 文件聲明**。引用：[agent.yaml#L9-L12](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/agent/agent.yaml#L9-L12), [AGENTS.md#L25-L26](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/AGENTS.md#L25-L26)。
2. **session continuity 只存兩個 id：`agent_session_id` 與 `previous_response_id`。** 代價是沒有 request id 去重；重送可能重跑工具，除非 skill/domain 自己 dedupe。證據層級：**原始碼明寫 + 推論**。引用：[bridge.py#L840-L843](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/desktop-client/charter_client/bridge.py#L840-L843), [bridge.py#L1155-L1159](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/desktop-client/charter_client/bridge.py#L1155-L1159)。
3. **stale transcript 的補救很特定：清 `previous_response_id`、不清 `agent_session_id`。** 代價是失去 in-memory conversation chain，但保住 `$HOME` state；若原操作其實已執行但只是不回文字，重試仍可能造成重複副作用。證據層級：**原始碼明寫 + 推論**。引用：[bridge.py#L999-L1026](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/desktop-client/charter_client/bridge.py#L999-L1026)。
4. **client 只做 process-local 單工與 UI busy，不做 durable queue。** 代價是 app crash / machine sleep 時沒有本地 job journal 來判斷上一個 turn 是否完成。證據層級：**原始碼明寫 + 推論**。引用：[bridge.py#L654-L682](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/desktop-client/charter_client/bridge.py#L654-L682), [app.js#L737-L771](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/desktop-client/assets/app.js#L737-L771)。
5. **Hosted server state 是 `$HOME` 檔案 + atomic replace，不用外部 state service。** 代價是缺少 CAS/ETag；同一 project 若真的並行寫同一 JSON，last writer wins。證據層級：**原始碼明寫 + 推論**。引用：[state.py#L149-L153](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/agent/src/charter_agent/state.py#L149-L153), [state.py#L186-L200](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/agent/src/charter_agent/state.py#L186-L200)。
6. **OAuth consent 當作 Responses stream 事件處理，不自建 consent 狀態機。** 代價是 client 固定等 8 秒後重試；如果使用者還沒完成 consent，可能再失敗/再需人工。證據層級：**原始碼明寫 + 推論**。引用：[bridge.py#L1017-L1026](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/desktop-client/charter_client/bridge.py#L1017-L1026), [protocol.py#L39-L56](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/desktop-client/charter_client/protocol.py#L39-L56)。
7. **tool authorization 靠 skill manifest + MAF/MCP allowlist；glob 則放寬。** 代價是宣告 `WorkIQMail2___*` 這類 glob 時，`skill_loader` 會把 toolbox surface 設成 unrestricted，實際控制回到 prompt/skill discipline。證據層級：**原始碼明寫**。引用：[skill_loader.py#L19-L30](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/agent/src/charter_agent/runtime/skill_loader.py#L19-L30), [reply-poll/SKILL.md#L10-L14](https://github.com/MSFT-Innovation-Hub-India/charter-agent/blob/92a44cf3705a53620a9d38db54304396652b1857/agent/skills/sow-response/reply-poll/SKILL.md#L10-L14)。
