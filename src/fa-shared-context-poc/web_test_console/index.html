設定

Team 加入的 connector（例如 Microsoft Teams）預設每位助理都能用。這裡只開關這位助理，而且只影響之後的新對話；進行中的對話不變。要加入、停用或改批准設定，請到左下 ⚙ 的「Agent Team 設定」→ Connectors。

skill 審核（整個 Team）

批准後這份 skill 對整個 Team 生效；要讓某位助理用，到助理清單那位助理右側的 ⚙ → Skills 打開並套用到新對話。批准本身不會開到任何助理。停用和拒絕都保留原內容與紀錄，不刪除。

新增 skill（自己寫一份草稿）

建立的是未批准的草稿，會出現在下方清單；查看內容後按「批准」才生效。相同內容只會建立一次。要修改既有 skill，請在這裡寫新的一份，再用「批准並取代」換掉舊的。

Team MCP（整個 Team，只有 Team 主人看得到）

這裡的 MCP 直接寫進 Team 自己的 Foundry toolbox：每次變更建立一個新版本並設成預設版本，舊版本保留，不刪除。新增後要到每位助理的設定（助理清單右側的 ⚙）→ MCP 打開並套用到新對話。每個 MCP 可設定「每次呼叫都要我批准」：助理每次要用它，都會先出現批准卡，列出工具名稱和參數。

新增 MCP

Connectors（整個 Team，只有 Team 主人能變更）

Connector 讓助理用你的帳號連到外部服務。加入後，Team 裡每位助理的新對話都能用；要讓某位助理不用，到那位助理的設定（助理清單右側的 ⚙）→ MCP 關掉。每次變更都建立新的 toolbox 版本並設為預設，舊版本保留，不刪除。

Team 真人批准規則（所有助理共用，最多 20 條）

先問我優先；自動允許不放寬原能力上限或審查拒絕，也不替舊的待批操作作決定。 這些規則管 shell、助理電腦（桌面）、交辦、助理之間傳話，以及不在 Toolbox 裡的 MCP。Toolbox 裡的 MCP 不看這裡：在「Team MCP」分頁替每個 MCP 設定「每次呼叫都要我批准」或「不用批准」。
已保存的原操作參照（純讀，不是待批或效果完成的證明）

排程只能在對話裡建立：助理提出每日時間和要做的事，你在批准卡上按「允許這次」才會生效。這裡列出這位助理的每日排程；停用會保存一個停用的新版本，下一次到點就不會執行。這裡不能修改或刪除；要改內容，請停用後在對話裡重新請助理提出。
